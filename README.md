# PATRICIUS — návrh webu

Moderný návrh stránky masážneho štúdia PATRICIUS v Žiline.

**Náhľad:** https://matejsmutny1-droid.github.io/patricius-masaze-navrh/

Statický web v HTML, CSS a JavaScripte bez build kroku. Na lokálne spustenie: `python3 -m http.server 8000`.

Publikovanie: GitHub Pages z vetvy `main`, priečinok `/ (root)`.

Obsah, kontakty, cenník a pôvodné fotografie prevádzky vychádzajú z https://www.patriciusmasaze.sk/. Návrh nemení oficiálnu doménu prevádzky. Objednanie odkazuje na oficiálnu kontaktnú stránku štúdia. Pôvodný sledovací odkaz nie je súčasťou verejného zdrojového kódu.
